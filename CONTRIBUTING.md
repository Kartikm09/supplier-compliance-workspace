# Contributing

Focused fixes, tests, documentation, and synthetic compliance scenarios are
welcome.

1. Open an issue with the behavior, security impact, and acceptance criteria.
2. Create a branch from `main`.
3. Keep every organization, identity, questionnaire, and document fictional.
4. Add tests at the layer that enforces the behavior.
5. Run `make verify` and the relevant pgTAP suite.
6. Submit a pull request with the commands and results you actually ran.

Never submit real supplier records, confidential documents, invitation tokens,
credentials, signed URLs, or buyer-internal notes. Reviews prioritize
relationship isolation, field confidentiality, state integrity, and functional
correctness over formatting preferences.
