# Responsible Disclosure

This repository contains an independent synthetic portfolio application, not a
customer production system.

For a potential security issue:

1. Do not include credentials, personal data, or exploit payloads in a public
   issue.
2. Use GitHub's private vulnerability-reporting channel when it is available.
3. Include the affected component, impact, safe reproduction conditions, and a
   suggested mitigation.
4. Use only the fictional fixtures in this repository.

Public issues remain appropriate for non-sensitive hardening ideas and
documentation corrections.
